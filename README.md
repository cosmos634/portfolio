# JOHA.DEV — Portfolio

A lightweight, responsive, Uzbek-language developer portfolio built with semantic HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` in a browser, or start a local static server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Configure Telegram contact

Open `script.js` and set `TELEGRAM_USERNAME` to your public Telegram username without the `@`. Until configured, the button points to the general Telegram site and the configuration note remains visible.
